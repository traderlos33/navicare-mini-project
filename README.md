# NaviCare Mini Project

A tiny fictional patient-support simulation built with plain HTML, CSS, and JavaScript.

## What this project teaches

1. **HTML** = the structure/content of the page.
2. **CSS** = how the page looks.
3. **JavaScript** = what happens when someone clicks something.
4. **Deployment** = putting these files on the internet so anyone can open the project.

## Run it locally

The easiest option:

1. Download/unzip this folder.
2. Double-click `index.html`.
3. It should open in your browser.
4. Click **Start Conversation**.
5. Try the three responses.

For a slightly more realistic developer workflow, open the folder in VS Code and use the **Live Server** extension.

## Files

- `index.html` — page structure and text
- `styles.css` — layout, typography, colors, responsive design
- `script.js` — button clicks, showing/hiding the scenario, and response feedback

## Your first editing exercise

Make three changes yourself:

1. In `index.html`, change the fictional patient's name.
2. In `styles.css`, change `--accent` to another dark color.
3. In `script.js`, rewrite one piece of feedback.

Refresh the browser after saving and watch your changes appear.

## Deploy it free with GitHub Pages

1. Create a GitHub repository.
2. Upload these project files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will give you a public URL.

The same folder can also be deployed with Netlify or Vercel.
